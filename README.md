# Expense Tracker

A full-stack web app for tracking and managing personal expenses.

## Features

- **Add, edit, and delete expenses**
- **Track account balance and total spending**
- **View spending by category**
- **Dashboard with spending statistics**
- **Persistent data with PostgreSQL**

## Tech Stack

- **Frontend:** React, Vite
- **Backend:** Java, Spring Boot
- **Database:** PostgreSQL

## Running Locally

```bash
# Frontend
cd frontend
npm install
npm run dev

# Backend
cd backend/expensetracker
./mvnw spring-boot:run
